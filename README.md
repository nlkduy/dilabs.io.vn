# Dilabs Website

A simple landing page for Dilabs, a company focused on production and community-oriented services.

## Features

- Hero section with background image
- Products section with featured items and links
- Contact section with email, phone, and address
- Favicon support

## Usage

Open `index.html` in a browser to view the page.

## Files

- `index.html` - main website markup
- `style.css` - styling for the page
- `script.js` - optional scripts
- `favicon.png` - favicon image
- `background.jpg` - hero section background image
